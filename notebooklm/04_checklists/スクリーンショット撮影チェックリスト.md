# スクリーンショット撮影チェックリスト

## 1. 目的

撮影漏れ・個人情報の写り込み・注釈ミス・ファイル名ズレを防ぐためのチェックリストです。

## 2. 撮影前チェック

| チェック | 内容 | 完了 |
|---|---|---|
| 1 | ChromeでKJM Shift＋を開いた | □ |
| 2 | ブラウザズームを100%にした | □ |
| 3 | 実運用PCに近い横幅にした | □ |
| 4 | テスト用またはダミーのスタッフ情報にした | □ |
| 5 | 実名・社員番号が写らない状態にした | □ |
| 6 | 保存先フォルダを作成した | □ |

## 3. 保存フォルダ

02_screenshots/00_common、01_global_shift、02_basic_rules、03_department_shift、04_staff、05_requests、06_backup、07_warnings、08_obic、09_manuals に分けます。

## 4. ファイル名ルール

`SS番号_画面名_操作名.png`

## 5. 注釈ルール

- 赤丸は押す場所・見る場所だけ。
- 操作順は番号で示す。
- 1枚あたり注釈は原則3〜5個。
- 危険操作には注意アイコンや強調を入れる。

## 6. 個人情報チェック

| 項目 | 対応 | 完了 |
|---|---|---|
| 実在スタッフ名 | ダミー化またはぼかし | □ |
| 社員番号 | ダミー化またはぼかし | □ |
| 個人の希望休 | ダミーデータ | □ |
| 勤務不可理由 | 写さない | □ |
| ブラウザ通知・ブックマーク | 写さない | □ |

## 7. 撮影完了判定

最優先画像が揃い、ファイル名が台帳と一致し、個人情報が写っておらず、関連本文のSS番号と一致していれば完了です。
