# UI変更時更新チェックリスト

## 1. 目的

KJM Shift＋の画面・機能・文言・出力仕様を変更したときに、NotebookLM用資料を更新し忘れないための保守用チェックリストです。

## 2. 更新が必要になる主な変更

| 変更内容 | 更新対象 |
|---|---|
| 画面名変更 | 全資料 |
| メニュー構成変更 | 全体概要、画面別、FAQ、スクショ台帳 |
| ボタン名変更 | 画面別、逆引き、FAQ、スクショ |
| 操作手順変更 | 画面別、逆引き、FAQ、トラブル |
| 新機能追加 | 全体概要、機能辞書、画面別、FAQ、逆引き |
| 機能削除 | 全資料から削除または注記 |
| 出力仕様変更 | FAQ、トラブル、用語集、画面別 |
| バックアップ仕様変更 | 回答ルール、FAQ、トラブル、用語集 |
| OBIC仕様変更 | 全体概要、FAQ、トラブル、用語集、画面別 |
| 休み種別変更 | 用語集、質問意図変換表、FAQ、逆引き |

## 3. 変更前チェック

変更前スクショ保存、バックアップ取得、影響資料洗い出し、Claude/Codex依頼時の範囲明確化を行います。

## 4. 変更後チェック

メニュー遷移、自動作成、確定、反映、希望休、集計・警告、バックアップ取得/復元、Excel/CSV/PDF、OBIC出力が動くか確認します。
