# 03_機能項目辞書

## 1. この資料の目的

この資料は、KJM Shift＋の機能や設定項目の意味をNotebookLMに理解させるための辞書です。質問に対して、正式な画面名・機能名・注意点・関連スクリーンショットIDを返せるようにします。

## 3. 混同しやすい機能

### 休み関連
| 言葉 | 正しい意味 | 画面 |
|---|---|---|
| 固定公休 | 毎週決まった曜日の休み | スタッフ |
| 祝日固定公休 | 祝日を毎回休みにする | スタッフ |
| 希望休 | 特定日の休み希望 | シフト希望・全体予定 |
| 勤務不可（「休」として登録） | 特定日に出勤できない日。現行アプリでは希望休と同じ「休」として登録（専用の選択肢なし） | シフト希望・全体予定 |
| 有休 | 登録場所は画面上で確認が必要 | 画面上で確認が必要 |
| 全体予定 | 全スタッフ共通の予定 | シフト希望・全体予定 |
| 定休日 | 店舗や運用上の曜日休み | 基本ルール |

### 出力関連
| 言葉 | 正しい意味 | 画面 |
|---|---|---|
| CSV出力 | 通常シフト表をCSVで出す | 全体シフト表 |
| Excel出力 | 通常シフト表をExcelで出す | 全体シフト表 |
| 印刷/PDF | 通常シフト表を印刷またはPDF保存 | 全体シフト表 |
| バックアップ取得 | 復元用JSON保存 | バックアップ |
| OBIC用Excel出力 | OBIC用休日データをExcelで出す | 〖店長〗OBIC連携用 |

## 4. 危険操作

編集モード、確定、基本ルール変更、スタッフ情報変更、シフト区分変更、必要人数変更、復元、初期化、OBIC連携用出力は、必ず注意喚起します。
