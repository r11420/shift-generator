# 07_用語集

## 1. この資料の目的

KJM Shift＋で使う用語を統一し、NotebookLMが画面名や機能を混同しないようにするための用語集です。

## 2. 用語一覧

| 用語 | 意味 |
|---|---|
| 本ツール | KJM Shift＋を指す。スタッフ向けには原則「本ツール」または「ツール」と表記する。 |
| 全体シフト表 | 確定済みの全体シフトを確認・出力する画面。 |
| 部署別シフト作成 | 部署ごとに自動作成し、確認後に確定する画面。 |
| 確定 | 部署別シフトを全体シフト表へ反映する操作。 |
| 編集モード | 全体シフト表を直接編集する注意操作。 |
| 締め月 | 15日締めの対象月度。 |
| 15日締め期間 | 締め月に対応する表示期間。 |
| 固定公休 | 毎週決まった曜日の休み。スタッフ画面で設定。 |
| 祝日固定公休 | 祝日を毎回休みにする設定。スタッフ画面で設定。 |
| 希望休 | 特定日の休み希望。シフト希望・全体予定で登録。 |
| 勤務不可 | 特定日に出勤できない日。現行アプリでは独立した選択肢ではなく、希望休と同じ「休」として登録する。 |
| 有休 | 登録場所は画面上で確認が必要。OBIC用では休日扱い。 |
| 全体予定 | 全スタッフ共通の予定。 |
| 定期予定 | 毎月・曜日などで繰り返す予定。基本ルールで設定。 |
| シフト区分 | A〜Sなどの勤務区分、時間、早中遅割当。 |
| 早番・中番・遅番 | シフト区分に割り当てられる時間帯区分。 |
| 必要人数 | 全体または部署ごとに必要な人数。 |
| 最大連勤 | 連続勤務の上限。 |
| 集計・警告 | 不足、連勤違反、希望未達などを確認する画面。 |
| バックアップ取得 | 復元用JSONファイルを保存する操作。 |
| バックアップから復元 | JSONから過去状態へ戻す操作。現在状態に影響する。 |
| すべて初期化 | 設定・シフト・希望を削除する危険操作。 |
| OBIC連携用 | OBIC取り込み用休日データを出す店長向け画面。 |
| 外部サロン管理システム | 予約・カルテ・売上などを扱う別システム。 |

## 3. 混同しやすい言葉

### 休み
- 固定公休：毎週決まった曜日の休み
- 希望休：特定日の休み希望
- 勤務不可：特定日に出勤できない日（現行アプリでは希望休と同じ「休」として登録）
- 有休：登録場所は画面上で確認が必要
- 全体予定：個人の休みではなく全スタッフ共通の予定

### 出力
- Excel出力：通常シフト表を出す
- バックアップ取得：復元用JSONを出す
- OBIC用Excel出力：休日/空欄形式のOBIC用データを出す
