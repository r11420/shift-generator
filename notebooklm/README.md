# KJM Shift＋ NotebookLM用マニュアル資料セット

## 1. この資料セットについて

この資料セットは、KJM Shift＋の操作マニュアルをNotebookLMに投入し、スタッフ・管理者・店長が質問形式で操作方法を確認できるようにするための資料一式です。

KJM Shift＋は、部署ごとにシフトを作成し、全体シフト表として確認・出力するためのツールです。基本の流れは以下です。

```text
部署別シフト作成 → 自動作成 → 作成結果の確認 → 確定 → 全体シフト表で確認 → 必要に応じて出力 → バックアップ取得
```

この資料セットでは、単なる操作手順だけではなく、NotebookLMが「どの画面を案内すべきか」「どの操作が危険操作か」「休み・出力・反映されない等の曖昧な質問をどう分岐するか」を判断できるようにしています。

## 4. 特に重要な回答ルール

### 画面名を必ず出す
例：希望休は「シフト希望・全体予定」画面で登録します。

### 「休み」は必ず分岐する
| 内容 | 使う画面 |
|---|---|
| 毎週決まった曜日の休み | スタッフ |
| 祝日を毎回休みにする | スタッフ |
| 特定日の休み希望 | シフト希望・全体予定 |
| 特定日に出勤できない | シフト希望・全体予定 |
| 有休 | 画面上で確認が必要 |

### 「出力」は必ず分岐する
| 出力したいもの | 使う画面 |
|---|---|
| 通常のシフト表CSV | 全体シフト表 |
| 通常のシフト表Excel | 全体シフト表 |
| 印刷/PDF | 全体シフト表 |
| 復元用バックアップJSON | バックアップ |
| OBIC用休日データ | 〖店長〗OBIC連携用 |

### 危険操作は注意喚起する
編集モード、確定、基本ルール変更、スタッフ情報変更、バックアップから復元、すべて初期化、OBIC連携用出力は、必ず影響範囲と確認事項を案内します。
