# 02_画面別完全マニュアル

## 1. この資料の目的

この資料は、KJM Shift＋の各画面について、目的・使い方・注意点・他画面との関係を整理した画面別マニュアルです。NotebookLMが正しい画面名、正しい操作手順、操作後の確認方法、関連スクリーンショットIDを案内できるようにすることを目的とします。

## 2. 画面別マニュアルの読み方

各画面は「目的」「主な利用者」「できること」「できないこと」「主な項目」「基本操作」「操作後の確認」「よくあるミス」「他画面との関係」「注意点」「関連スクリーンショットID」で整理します。

## 3. 全体シフト表

### この画面の目的
確定されたシフトを全体で確認する画面です。通常は参照用で、CSV、Excel、印刷/PDFの出力もここから行います。

### 主な利用者
一般スタッフ、管理者、店長。

### この画面でできること
- 全体シフトの確認
- 締め年・締め月の変更
- 15日締め期間の確認
- CSV出力、Excel出力、印刷/PDF
- 必要時の編集モード切替
- 部署別シフト作成への移動

### この画面でできないこと
希望休登録は「シフト希望・全体予定」、固定公休は「スタッフ」、必要人数やシフト区分は「基本ルール」、復元用バックアップは「バックアップ」、OBIC用休日データは「〖店長〗OBIC連携用」で行います。

### 基本操作手順
1. 「全体シフト表」を開きます。
2. 締め年・締め月を確認します。
3. 15日締め期間を確認します。
4. 対象日・対象スタッフのシフトを確認します。
5. 出力する場合は「ファイル出力」からCSV、Excel、印刷/PDFを選びます。

### 注意点
編集モードは全体シフトを直接変更するため、管理者向けの注意操作です。通常Excel出力とOBIC連携用Excel出力は別物です。Excel出力はバックアップではありません。

### 関連スクリーンショットID
SS-101 / SS-102 / SS-104 / SS-105 / SS-106 / SS-107 / SS-109 / SS-110 / SS-111 / SS-112

## 4. 部署別シフト作成

### この画面の目的
部署ごとにシフトを自動作成し、作成結果を確認してから確定する画面です。確定した内容が全体シフト表に反映されます。

### 基本フロー
```text
部署を選ぶ → 自動作成 → 作成結果を確認 → 確定 → 全体シフト表で確認
```

### 主な利用者
管理者、店長。一般スタッフは原則操作対象外です。

### この画面でできること
- 対象部署の選択
- 自動作成
- 作成結果の確認
- 確定
- トリマー月次表の確認

### この画面でできないこと
希望休登録、固定公休設定、必要人数変更、シフト区分変更、バックアップ、OBIC出力。

### 基本操作手順
1. 「部署別シフト作成」を開きます。
2. 対象締め月を確認します。
3. 対象部署を選びます。
4. 「自動作成」を選びます。
5. 作成結果を確認します。
6. 「集計・警告」で人数不足・連勤違反・希望未達を確認します。
7. 問題がなければ「確定」を選びます。
8. 「全体シフト表」で反映を確認します。

### 注意点
自動作成と確定は別操作です。確定は全体シフト表に反映される重要操作です。確定してよいかどうかは管理者判断です。

### 関連スクリーンショットID
SS-301 / SS-302 / SS-303 / SS-304 / SS-305 / SS-306 / SS-307 / SS-308 / SS-309 / SS-310

## 5. シフト希望・全体予定

### この画面の目的
スタッフごとの希望休、早番希望、中番希望、遅番希望などを登録する画面です。「勤務不可（その日出勤できない）」も、現行アプリでは独立した選択肢ではなく、希望休と同じ「休」として登録します。全スタッフ共通の全体予定も登録します。登録内容は締め月ごとに保持されます。

### 主な利用者
管理者、店長。一般スタッフは運用により確認のみ。

### この画面でできること
- 部署プルダウンで絞り込み
- スタッフ別タブの選択
- 希望休、早番希望、中番希望、遅番希望の登録（「勤務不可」も希望休と同じ「休」として登録）
- 全体予定の登録
- 登録済み希望の編集・削除

### この画面でできないこと
毎週の固定公休と祝日固定公休は「スタッフ」、定休日と定期予定は「基本ルール」で扱います。有休の登録場所は画面上で確認が必要です。

### 基本操作手順
1. 「シフト希望・全体予定」を開きます。
2. 対象締め月を確認します。
3. 部署プルダウンで対象部署を選びます。
4. 対象スタッフのタブを選びます。
5. 日付と種別を選びます。
6. 保存します。
7. 登録後の一覧で確認します。
8. 必要に応じて部署別シフト作成で再作成し、集計・警告で希望未達を確認します。

### 注意点
希望休は特定日の休み希望、固定公休は毎週決まった曜日の休みです。勤務不可（その日出勤できない日）は、現行アプリでは独立した選択肢ではなく、希望休と同じ「休」として登録します（自動作成上の優先度は断定しません）。全体予定は個人の休みではありません。

### 関連スクリーンショットID
SS-501 / SS-502 / SS-503 / SS-504 / SS-505 / SS-506 / SS-507 / SS-508 / SS-509 / SS-510 / SS-511 / SS-512 / SS-513 / SS-514 / SS-515

## 6. 基本ルール

### この画面の目的
最大連勤、必要人数、シフト区分、定期予定、タグなど、シフト作成の前提条件を設定する画面です。

### 主な利用者
管理者、店長。一般スタッフは原則操作対象外です。

### この画面でできること
- 共通ルール・部署別ルールの設定
- 最大連勤、試行回数、遅番→翌日早番回避
- 土日祝必要人数扱い
- スタッフタグ一覧、全体予定タグ一覧
- 定期予定、定休日の曜日
- 全体最低人数、平日/土日祝の全体早遅
- シフト区分、区分デザイン設定
- 部署別必要人数、責任者最低人数

### 基本操作手順
1. 「基本ルール」を開きます。
2. 変更したい項目を確認します。
3. 必要な値を変更します。
4. 部署別シフト作成で再作成します。
5. 集計・警告で不足や違反を確認します。
6. 全体シフト表で結果を確認します。

### 注意点
基本ルール変更は自動作成結果全体に影響します。シフト区分変更は時間、早中遅割当、集計に影響します。区分デザイン設定は見た目の色設定であり、勤務時間変更ではありません。スタッフタグの具体用途と責任者判定条件は画面上または実装で確認が必要です。

### 関連スクリーンショットID
SS-201〜SS-222

## 7. スタッフ

### この画面の目的
スタッフ情報を登録・編集する画面です。所属部署、社員番号、氏名、固定公休、祝日固定公休、兼務可能部署などを管理します。

### 主な利用者
管理者、店長。一般スタッフは原則操作対象外です。

### この画面でできること
- 部署タブ切替
- スタッフ追加
- 社員番号・氏名の入力
- 同姓同名時の識別（氏名表記や社員番号で見分け。具体的な方法は画面上で確認）
- 固定公休、祝日固定公休
- 兼務可能部署
- 社員番号順の確認

### この画面でできないこと
特定日の希望休、早中遅希望、全体予定は「シフト希望・全体予定」で登録します。勤務不可として扱いたい日も、同じ画面で「休」として登録します（勤務不可専用の選択肢はありません）。

### 基本操作手順
1. 「スタッフ」を開きます。
2. 対象部署のタブを選びます。
3. 対象スタッフを確認、または「この部署にスタッフを追加」を選びます。
4. 社員番号、氏名、固定公休、祝日固定公休、兼務可能部署を設定します。
5. 一覧に反映されているか確認します。
6. 部署別シフト作成で候補に出るか確認します。

### 注意点
スタッフ情報変更は、自動作成候補やOBIC連携用の並びに影響します。スタッフ削除または無効化の有無・操作方法は画面上で確認が必要です。

### 関連スクリーンショットID
SS-401〜SS-413

## 8. 集計・警告

### この画面の目的
スタッフ別回数、部署別不足、全体早遅不足、連勤違反、希望未達などを確認する画面です。確定前や修正後の確認に使います。

### 主な利用者
管理者、店長。

### この画面でできること
- スタッフ別回数の確認
- 部署別不足の確認
- 全体早遅不足の確認
- 連勤違反の確認
- 希望未達の確認
- 警告詳細の確認、警告がない状態の確認（警告の有無は登録内容により変わります）

### 基本操作手順
1. 「集計・警告」を開きます。
2. スタッフ別回数、部署別不足、全体早遅不足、連勤違反、希望未達を順に確認します。
3. 問題がある場合は対象日・対象スタッフ・対象部署を確認します。
4. 関連画面で修正します。
5. 修正後に再度「集計・警告」を確認します。

### 注意点
警告を無視してよいかはNotebookLMが断定しません。警告の許容操作の有無や仕様は画面上で確認が必要です。

### 関連スクリーンショットID
SS-701〜SS-709

## 9. バックアップ

### この画面の目的
設定・作成済みシフト・希望などをJSONファイルとして保存・復元する画面です。

### 主な利用者
管理者、店長。一般スタッフは原則操作対象外です。

### この画面でできること
- バックアップ取得（JSON保存）
- バックアップから復元
- すべて初期化

### この画面でできないこと
CSV、Excel、印刷/PDF、OBIC用Excel出力は別画面です。

### 基本操作手順
#### バックアップ取得
1. 「バックアップ」を開きます。
2. 「バックアップ取得（JSON保存）」を選びます。
3. JSONファイルが保存されたか確認します。

#### 復元
1. 復元前に現在の状態をバックアップ取得します。
2. 「バックアップから復元」を選びます。
3. 復元したいJSONファイルを選びます。
4. 復元後、全体シフト表・スタッフ・希望を確認します。

#### 初期化
1. 初期化前に現在の状態をバックアップ取得します。
2. 「すべて初期化」を選びます。
3. 確認表示が出た場合は内容を確認します。
4. 初期化後、各画面を確認します。

### 注意点
バックアップはJSONファイルです。Excel、CSV、PDFはバックアップではありません。復元は現在の状態に影響する可能性があります。初期化は設定・作成済みシフト・希望を削除する危険操作です。

### 関連スクリーンショットID
SS-601〜SS-609

## 10. 〖店長〗OBIC連携用

### この画面の目的
OBIC取り込み用の休日データを確認・出力する店長向け画面です。通常のシフト表ではありません。

### OBIC連携用での扱い
| 状態 | 扱い |
|---|---|
| 公休 | 休日 |
| 希望休 | 休日 |
| 有休 | 休日 |
| 勤務シフト | 空欄 |
| その他 | 空欄 |

### この画面でできること
- 休日データ確認
- 対象締め月確認
- 社員番号昇順確認
- コピー
- OBIC用Excel出力

### 基本操作手順
1. 「全体シフト表」で対象締め月を確認します。
2. 「〖店長〗OBIC連携用」を開きます。
3. 公休・希望休・有休が「休日」になっているか確認します。
4. 勤務シフトやその他が空欄になっているか確認します。
5. 「コピー」または「Excel出力」を選びます。
6. 出力結果を確認します。

### 注意点
通常のExcel出力とは別物です。勤務日が空欄なのはOBIC用の扱いです。OBIC本体への直接登録は本ツールの対象外です。

### 関連スクリーンショットID
SS-801〜SS-809

## 11. 使い方マニュアル

詳しい操作手順を確認するための資料です。メニューから開き、別タブで確認します。詳細確認用です。関連スクリーンショットID：SS-901 / SS-903。

## 12. クイックマニュアル

よく使う操作を短く確認するための資料です。詳細が必要な場合は使い方マニュアルやNotebookLMに誘導します。関連スクリーンショットID：SS-902 / SS-903。

## 13. 画面間の関係

```text
基本ルール → スタッフ → シフト希望・全体予定 → 部署別シフト作成 → 集計・警告 → 確定 → 全体シフト表 → 出力 → バックアップ
```

| やりたいこと | 使う画面 |
|---|---|
| 毎週決まった曜日を休みにする | スタッフ |
| 特定日の希望休を入れる | シフト希望・全体予定 |
| シフトを自動作成する | 部署別シフト作成 |
| 警告を確認する | 集計・警告 |
| 通常のExcelを出す | 全体シフト表 |
| 復元用JSONを取る | バックアップ |
| OBIC用休日データを出す | 〖店長〗OBIC連携用 |

## 14. 危険操作まとめ

| 操作 | 画面 | 注意点 |
|---|---|---|
| 編集モード | 全体シフト表 | 全体シフトを直接変更する可能性 |
| 確定 | 部署別シフト作成 | 全体シフト表へ反映 |
| 基本ルール変更 | 基本ルール | 自動作成結果全体に影響 |
| スタッフ情報変更 | スタッフ | 候補・表示順・OBIC連携に影響 |
| バックアップから復元 | バックアップ | 現在状態が変わる可能性 |
| すべて初期化 | バックアップ | 設定・シフト・希望が削除される |
| OBIC連携用出力 | 〖店長〗OBIC連携用 | 店長向け・勤怠連携に関わる |

## 15. NotebookLM回答時の参照ルール

1. 画面名を明記する。
2. 手順を番号付きで書く。
3. 操作後の確認方法を書く。
4. 危険操作には注意喚起する。
5. 不明点は推測しない。
6. 関連スクリーンショットIDを付ける。
7. OBIC、バックアップ、通常出力を混同しない。
8. 固定公休、希望休、勤務不可、有休を混同しない。
