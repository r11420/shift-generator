# 01_全体概要

## 1. 本資料の目的

この資料は、KJM Shift＋の全体像をNotebookLMに理解させるための概要資料です。画面構成、基本フロー、利用者別の役割、別システムとの違い、危険操作を整理します。

## 2. 本ツールの名称

正式名称は **KJM Shift＋** です。スタッフ向けには「本ツール」「ツール」「KJM Shift＋」と表記します。OBICや外部サロン管理システムと区別する場合は「別システム」と表記します。

## 3. 本ツールの目的

KJM Shift＋は、15日締めのシフトを部署別に作成し、全体シフト表として確認・出力するためのツールです。

```text
部署別シフト作成 → 自動作成 → 確認 → 確定 → 全体シフト表で確認 → 出力 → バックアップ取得
```

## 4. 画面一覧

| 画面 | 役割 | 主な利用者 |
|---|---|---|
| 全体シフト表 | 確定済み全体シフトの確認・出力 | 全員/管理者 |
| 部署別シフト作成 | 部署ごとの自動作成・確認・確定 | 管理者 |
| シフト希望・全体予定 | 希望休、勤務不可、早中遅希望、全体予定の登録 | 管理者 |
| 基本ルール | 最大連勤、必要人数、シフト区分などの前提設定 | 管理者 |
| スタッフ | スタッフ追加、固定公休、兼務可能部署など | 管理者 |
| 集計・警告 | 不足、連勤違反、希望未達などの確認 | 管理者/店長 |
| バックアップ | JSONバックアップ取得・復元・初期化 | 管理者 |
| 〖店長〗OBIC連携用 | OBIC取り込み用休日データ出力 | 店長 |
| 使い方マニュアル | 詳細手順の確認 | 全員 |
| クイックマニュアル | よく使う操作の短縮手順 | 全員 |

## 5. 本ツールでできること

- 部署別シフトの自動作成
- 作成結果の確認と確定
- 全体シフト表の確認
- 希望休・勤務不可・早中遅希望の登録
- 固定公休・祝日固定公休の設定
- 必要人数・最大連勤・シフト区分の設定
- 集計・警告の確認
- CSV、Excel、印刷/PDF出力
- 復元用JSONバックアップ取得
- OBIC取り込み用休日データの出力

## 6. 本ツールでできないこと

- 外部サロン管理システムの予約、カルテ、売上管理
- OBIC本体への直接登録
- 勤怠・給与計算そのもの
- 複数端末での自動同期の断定
- 有休登録場所の断定

## 7. データ保存の考え方

入力内容は端末内に保存される前提です。端末変更やデータ消失に備えて、定期的に「バックアップ」画面からJSONファイルを取得します。Excel、CSV、PDFはバックアップではありません。

## 8. 利用者別の主な操作

| 利用者 | 主な操作 |
|---|---|
| 一般スタッフ | 全体シフト表、使い方マニュアル、クイックマニュアルの確認 |
| 管理者 | 部署別シフト作成、希望登録、スタッフ編集、基本ルール、集計・警告、バックアップ |
| 店長 | 全体確認、OBIC連携用データ確認・出力 |

## 9. 危険操作

| 操作 | 注意点 |
|---|---|
| 編集モード | 全体シフトを直接変更する可能性がある |
| 確定 | 全体シフト表へ反映される |
| 基本ルール変更 | 自動作成結果全体に影響する |
| スタッフ情報変更 | 候補・表示順・OBIC連携に影響する |
| バックアップから復元 | 現在の状態が変わる可能性がある |
| すべて初期化 | 設定・作成済みシフト・希望が削除される |
| OBIC連携用出力 | 店長向け・勤怠連携に関わる |
