# 06_トラブルシューティング

## 1. この資料の目的

KJM Shift＋で「反映されない」「警告が出る」「出力がおかしい」などが起きたとき、原因を断定せず順番に切り分けるための資料です。

## 2. 共通確認事項

1. 締め月が合っているか。
2. 対象部署が合っているか。
3. 対象スタッフが合っているか。
4. 確定済みか。
5. 希望休・勤務不可の登録月が合っているか。
6. バックアップ復元・初期化の影響がないか。

## シフトが全体シフト表に反映されない

### まず確認する画面
関連する操作画面と、全体シフト表・集計/警告を確認します。

### 考えられる原因
- 自動作成だけで確定していない
- 締め月が違う
- 部署が違う
- スタッフ設定が違う
- 復元で古い状態に戻っている

### 確認手順
1. 部署別シフト作成で確定済みか確認
2. 全体シフト表で締め月を確認
3. 対象部署と対象スタッフを確認
4. 必要なら再作成・確定

### 注意点
危険操作や未確認仕様は断定せず、管理者または画面上で確認してください。
