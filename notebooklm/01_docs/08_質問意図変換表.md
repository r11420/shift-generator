# 08_質問意図変換表

## 1. この資料の目的

スタッフや管理者が自然な言い方で質問したときに、NotebookLMが正しい意図を読み取り、適切な画面・機能・回答方針へ変換するための資料です。

## 2. 基本判断ルール

- 「休み」は固定公休、祝日固定公休、希望休、勤務不可、有休、全体予定、定休日に分岐する。
- 「出力」はCSV、Excel、印刷/PDF、バックアップJSON、OBIC用コピー/Excelに分岐する。
- 「反映されない」は、締め月、確定、部署、スタッフ、希望登録、復元/初期化を順に確認する。
- 「タグ」はスタッフタグと全体予定タグに分岐する。
- 未確認仕様は断定しない。

```text
1. 対象締め月を確認します。

3. 該当機能を操作します。
4. 操作後に反映を確認します。
関連スクリーンショット：SS-xxx
```
