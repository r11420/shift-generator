# 05_FAQ

## 1. この資料の目的

KJM Shift＋についてスタッフ・管理者・店長からよく出る質問に対し、NotebookLMがそのまま回答しやすい形で整理したFAQです。

## Q001. KJM Shift＋は何をするツールですか？

### 回答
部署ごとのシフトを作成し、全体シフト表として確認・出力するためのツールです。

### 案内する画面
- 全体シフト表 / 部署別シフト作成

### 確認すること
- 対象締め月・部署・スタッフが合っているか
- 操作後に反映確認できているか

### 注意点
危険操作や未確認仕様に関わる場合は、管理者または画面上で確認してください。

### 関連スクリーンショットID
- SS-001 / SS-101 / SS-301
